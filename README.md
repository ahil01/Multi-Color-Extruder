# Multi-Color-Extruder
ARC M1 Custom BMG Extruder is a lightweight direct-drive extruder for high-speed multi-color 3D printing. It works with the custom ARC M1 AMS and the Enraged Rabbit Carrot Feeder (ERCF). Dual-drive gears provide strong grip, precise extrusion, reliable filament changes, and broad material support. Modular design enables easy maintenance. Efficient.
